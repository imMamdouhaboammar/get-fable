# get-fable — Public Distribution Edition

- **Repository Role:** Public Distribution & Community Runtime
- **Visibility:** PUBLIC
- **License:** GNU AGPLv3 (Affero GPL v3)
- **Included Content:** Canonical runtime CLI (`bin/get-fable.js`), production skills (`skills/`), packs, recipes, hooks, and integration manifests.
- **Source of Truth:** Development is conducted in the private core repository (`get-fable-core`). Public releases and updates are compiled and synced unidirectionally via `export-public-cut.ts`.
- **Contribution Policy:** Contributions, issues, and bug fixes are welcome under the AGPLv3 license. All contributions are tested via CI and merged into core.
