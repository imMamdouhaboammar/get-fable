# get-fable — Public Distribution Edition

- **Repository Role:** Public Skills Ecosystem, Architecture Documentation & Community Hub
- **Visibility:** PUBLIC
- **License:** GNU AGPLv3 (Affero GPL v3)
- **Included Content:** 44 Canonical Skills (`skills/`), Skill Packs (`packs/`), Registry (`registry/`), Architecture & Research Docs (`docs/`), Roadmap (`ROADMAP.md`), and Integration Plugins.
- **Source of Truth:** Development of the core engine and runtime is conducted in the private core repository (`get-fable-core`). Public releases and updates are compiled and synced unidirectionally via `export-public-cut.ts`.
- **Runtime Installation:** The Fable CLI runtime is installed via npm (`npx get-fable` or `npm install -g get-fable`) or the automated shell installer (`install.sh`).
- **Contribution Policy:** Contributions, issues, and bug fixes are welcome under the AGPLv3 license.
