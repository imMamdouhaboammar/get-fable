# get-fable

A complete coding lifecycle governance kernel for AI agents.

## Core Routing & Specialists

### Core Pack (`core`)
- `get-fable`: Universal front-door router and orchestrator
- `fable-discover`: Grounding and execution path exploration
- `fable-plan`: Architecture, migration plans, and task decomposition
- `fable-execute`: Focused implementation within bounded cards
- `fable-verify`: Machine-checked test, build, and runtime evidence
- `fable-recover`: Deterministic failure diagnosis and loop recovery

### Intelligence & Build Packs (`intelligence`, `build`)
- `fable-research`: Primary source and official documentation research
- `fable-tdd`: Test-driven development with red-green verification
- `fable-delegate`: Bounded parallel work delegation across subagents

### Proof & Delivery Packs (`proof`, `delivery`, `evolution`)
- `fable-review`: Independent diff and correctness review
- `fable-security`: Security boundary review and threat mitigation
- `fable-release`: Release readiness, packaging, and version consistency
- `fable-handoff`: Context preservation and next-session handoffs
- `fable-eval`: Holdout evaluation and benchmark scoring

### System & Harness Pack (`system`)
- `fable-dataviz`: Accessible data visualizations, charts, plots, and dashboards
- `fable-artifact`: Structured technical proposals, responsive artifacts, and diagrams
- `fable-simplify`: Zero-regression code simplification and altitude cleanup
- `fable-loop`: Bounded recurring task loops and interval polling
- `fable-run`: Live app runtime execution and smoke testing
- `fable-memory`: Persistent file-based memory system and knowledge indexing
- `fable-config`: Agent harness parameters, allowlist permissions, and hook configuration
- `fable-simulator`: Rigorous truthfulness, independent verification oracles, and contract derivation
- `fable-cowork`: Autonomous cowork execution, silent tool chaining, and safety boundaries
- `fable-spark`: Situational awareness micro-policy predicting atomic next moves
