get-fable Documentation

This documentation reflects the authoritative structure defined in README.md.

Requirements

  • Bun runtime
  • Python 3 for lifecycle hooks
  • Git if cloning from source

Inspect Before Installing

Inspect the installation state and enumerate bundled assets directly from source:

git clone https://github.com/imMamdouhaboammar/get-fable.git
cd get-fable

bun ./bin/get-fable.js status
bun ./bin/get-fable.js assets

Add get-fable to a Project

Initialize Fable discipline inside a single working directory:

bun /path/to/get-fable/bin/get-fable.js init

Creates the following files without overwriting existing files:

.fable/
  LEDGER.md
  PROGRESS.md
  VERIFIER_PROMPT.md

.agents/
  skills/fable-mode/SKILL.md
  rules/fable5-mode.md

docs/
  SPEC.md

Global Integration Install

Install global integrations across detected agent environments:

bun ./bin/get-fable.js install

Writes to the following locations:

  • ~/.claude/: Installs Fable Mode skill and 4 lifecycle hooks.
  • ~/.gemini/config/: Installs Antigravity plugin package, skill files, and rules.
  • ~/.agent-kernel/: Copies Fable rules when directory exists.

Workflow Behavior

  1. Define work: docs/SPEC.md captures goals, tasks, acceptance checks, and decisions.
  2. Keep state visible: .fable/LEDGER.md tracks task state outside chat context.
  3. Gate transitions: Hooks intervene at session start, tool use, command failures, and turn close.
  4. Handle failures: The fail-streak hook shifts execution away from blind retries toward root cause analysis.
  5. Close with evidence: The close guard verifies ledger completion and evidence annotations before close.

Lifecycle Hooks

Plain Python scripts located in hooks/:

  • SessionStart: fable_profile_inject.py
  • PreToolUse: fable_spawn_guard.py
  • PostToolUse: fable_fail_streak.py
  • Stop: fable_close_guard.py

Request Proxy Server

export UPSTREAM_OPENAI_URL="https://your-provider.example/v1/chat/completions"
bun ./bin/get-fable.js serve 8080

Without UPSTREAM_OPENAI_URL, the server returns an enrichment preview instead of calling an upstream provider.
