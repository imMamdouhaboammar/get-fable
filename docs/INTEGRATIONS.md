# External Integrations Guide

## Ecosystem Bindings
- **GitHub**: Automatic PR reviews, branch status checks, issue triage.
- **Search**: WebSearch adapters with primary-source bias.
- **Security**: Threat modeling, vulnerability scanning, secret hygiene.
- **Browser**: Headless automation via Playwright and Chrome DevTools MCP.
- **External Agents**: Peer-agent delegation and structured handoff protocols.
