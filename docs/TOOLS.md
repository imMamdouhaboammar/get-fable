# Tool Capabilities & Schema Binding

## Abstract Capabilities
1. `filesystem-operations`: Workspace file read/write/edit.
2. `shell-execution`: Deterministic script and test runner execution.
3. `current-source-search`: Authoritative external web documentation search.
4. `browser-inspection`: Headless browser playthrough and screenshot proof.
5. `git-inspection`: Non-destructive version control queries.
