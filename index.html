What if the model you already use
could work more like a frontier model?

get-fable improves the harness around your model: providing specs, persistent task state, lifecycle hooks, reusable skills, failure handling, evidence checks, and a request proxy.

The Thesis

📋

1. Plan before implementation

Captures requirements and tasks in docs/SPEC.md before code execution starts.

📁

2. Keep task state outside the chat

Stores task progress in .fable/LEDGER.md, PROGRESS.md, and VERIFIER_PROMPT.md so context survives across turns.

⚙️

3. Carry working rules across turns

Injects .agents/skills/fable-mode/SKILL.md and .agents/rules/fable5-mode.md into global agent environments.

🔄

4. React to repeated failures

The fail-streak hook shifts behavior away from blind retries toward identifying root failure classes.

🧩

5. Reusable skills & agent definitions

Bundles prompts, agents, skills, slash-command references, reminders, MCP definitions, and starter components.

🔍

6. Require observable evidence

The close guard checks for unresolved ledger items and missing evidence annotations before turn completion.

What get-fable Changes

Project Discipline
Creates project spec, task ledger, progress file, verifier prompt, workspace skill, and workspace rules.
Claude Code
Installs Fable Mode skill and 4 lifecycle hooks into ~/.claude/.
Antigravity / Gemini
Installs plugin package, skill files, and rules under ~/.gemini/config/.
Agent Kernel
Copies Fable rules when ~/.agent-kernel/ directory exists on the system.

Lifecycle Hooks

⚡

SessionStart

fable_profile_inject.py: Reintroduces project state and working rules at the beginning of each session.

🛡️

PreToolUse

fable_spawn_guard.py: Checks prerequisites before selected agent or task actions run.

🎯

PostToolUse

fable_fail_streak.py: Detects repeated command failures and interrupts blind retry loops.

🏁

Stop

fable_close_guard.py: Verifies unresolved ledger items and evidence before releasing turn control.

Request Proxy Router

Start the local proxy server to enrich requests with Fable context:

bun ./bin/get-fable.js serve 8080

Exposes POST /v1/chat/completions. Normalizes OpenAI-style messages and Gemini-style contents arrays, prepends Fable context, and forwards to UPSTREAM_OPENAI_URL when set.
