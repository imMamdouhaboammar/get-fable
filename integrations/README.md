# Fable Integrations

## Overview
Optional external adapters for deep tool integrations:
- `github/`: PR review, issue triage, branch status.
- `search/`: Web search, Tavily, Brave, Google Search.
- `security/`: Scanners, secret detectors, SAST.
- `browser/`: Playwright, Puppeteer, Chrome DevTools MCP.
- `external-agents/`: Claude Code, Codex, Antigravity, OpenCode interoperability.
