# Context & Communication Policy

## Core Principle
Communicate outcomes clearly, minimize mid-chain noise, and respect token discipline.

## Rules
1. **Outcome First**: Begin final turn responses with the direct answer or TLDR.
2. **Prose Over Bullets**: Use clean prose paragraphs for reports; reserve bullet lists for enumerable data.
3. **CommonMark Blank Lines**: Insert blank lines before and after headers and list blocks for correct rendering.
4. **Quiet Tool Chaining**: Suppress intermediate narrative filler between tool invocations.
