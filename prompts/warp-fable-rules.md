# Warp AI — get-fable Working Rules

Terminal-first lifecycle discipline for Warp AI.

## Rules

1. **Route Intent**: Run `get-fable route "<task>"` before starting substantial work.
2. **Track Mutations**: Execute `get-fable mutation` when modifying files.
3. **Verify Freshly**: Always run tests and verify following the latest code change.
4. **Diagnose Failures**: Use `fable-recover` when errors repeat.
5. **Spark Advice**: Run `get-fable spark` for concise next-step guidance.
