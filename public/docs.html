get-fable Documentation

The Fable 5 Mythos System brings Anthropic's internal Claude Code process discipline to every AI model and coding agent.

Quickstart Installation

Install get-fable with a single command. The installer automatically detects your active environment and provisions your agent platforms.

# Using Bun (Recommended)
bunx get-fable install

# Using npm
npx get-fable install

Antigravity & Gemini CLI Integration

Installs as a native Antigravity plugin: registering global rules, skills, and mechanical hooks directly in ~/.gemini/config.

bunx get-fable install-antigravity

Once installed, start or restart any Antigravity session to automatically load the Fable 5 system prompt and process rules.

Project Initialization

Bootstrap Fable Mode process discipline into any project repository:

bunx get-fable init

This command creates the following structure in your working directory:

  • .fable/LEDGER.md: Task tracker with acceptance criteria and evidence fields.
  • docs/SPEC.md: Project specification template.
  • .agents/skills/: Custom local skill directory.
  • .agents/rules/: Project-level enforcement rules.

Mythos Router Proxy

Wrap any LLM provider (OpenAI GPT-4o, Ollama, Anthropic) with Fable-grade context injection via a lightweight local proxy server:

bunx get-fable serve 8080

Then configure your agent or client to use http://localhost:8080 as its Base URL endpoint.
