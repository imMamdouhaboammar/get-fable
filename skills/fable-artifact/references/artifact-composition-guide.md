# Artifact Composition Guide

## Best Practices
1. **Clear Hierarchy**: Use `#`, `##`, and `###` logically.
2. **Mermaid Diagrams**: Quote labels containing special characters, e.g. `id["Node (Details)"]`.
3. **Alerts**: Use `> [!NOTE]`, `> [!IMPORTANT]`, and `> [!WARNING]` sparingly for key highlights.
4. **Self-Contained**: Ensure code blocks specify explicit language syntax highlighting.
