# Data Visualization Design System

## Core Standards
1. **Responsive ViewBox**: Always specify `viewBox="0 0 W H"` without hardcoded fixed width/height attributes.
2. **Accessible Contrast**: Foreground elements must have min 4.5:1 contrast against chart backgrounds.
3. **Semantic Colors**: Use muted palettes for baseline categories and high-saturation accents for highlights.
4. **Data Labels**: Position labels near data points to reduce reliance on distant legends.
