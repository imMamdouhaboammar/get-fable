# Example: Recording User Testing Preference

## Action
Record that the user requires Bun test runner instead of Jest.

## File: `.memory/prefer-bun-test.md`
```markdown
---
name: prefer-bun-test
description: Use Bun test runner for all JavaScript/TypeScript projects
metadata:
  type: preference
---
Always run tests using `bun test`. Do not install or invoke Jest or Mocha.
```
