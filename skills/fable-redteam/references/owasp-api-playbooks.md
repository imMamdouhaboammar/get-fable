# OWASP API Security Playbooks

1. **API1:2023 - Broken Object Level Authorization (BOLA):** Verify that resource IDs in requests cannot be modified to access objects of other users/tenants.
2. **API2:2023 - Broken Authentication:** Test missing headers, expired tokens, null tokens, and algorithmic signature bypass.
3. **API3:2023 - Broken Object Property Level Authorization:** Check excessive data exposure and mass assignment vulnerabilities.
4. **API5:2023 - Broken Function Level Authorization (BFLA):** Check whether standard user tokens can access administrative endpoints.
