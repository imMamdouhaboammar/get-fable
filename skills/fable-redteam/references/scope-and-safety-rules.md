# Scope & Safety Rules

1. **Authorization Mandatory:** Never scan an IP or domain without written authorization or ownership.
2. **Safe Mode Active:** By default, all scans run in non-destructive mode. DoS attacks, database drop operations, and heavy brute-force exceeding rate limits are prohibited.
3. **Localhost & Staging Isolation:** Production scans must be limited to passive non-intrusive reconnaissance unless explicitly approved.
