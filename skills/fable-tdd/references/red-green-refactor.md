# Test-Driven Development (TDD) Discipline

## Cycle
1. **Red**: Write a focused test expressing the expected behavior. Run test and verify it fails for the expected reason.
2. **Minimal Green**: Write the smallest amount of code to make the test pass.
3. **Refactor**: Clean up duplication and improve structure while keeping tests passing.
4. **Invariant**: Never skip observing the red failure state.
